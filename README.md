# PAWS Jaipur website — GitHub Pages ready

## Publish on GitHub
1. Create a **public** GitHub repository, e.g. `paws-jaipur`.
2. Click **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js` and the complete `images` folder (keep the same folder structure). If the GitHub upload screen does not accept a folder, drag the whole folder from your computer.
4. Click **Commit changes**.
5. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select `main` and `/(root)`, then **Save**.
6. Wait for Pages to publish. Your address will usually be `https://YOUR-USERNAME.github.io/paws-jaipur/`.

## Update later
Open the repository, select a file, click the pencil icon, edit and **Commit changes**. To replace pictures, upload new files with the same filenames inside `images`. Wait for deployment, then refresh with Ctrl+Shift+R.
